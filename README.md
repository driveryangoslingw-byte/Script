# Bosch USB Lab 3.0 (Android / Intuvia BES2)

Экспериментальная диагностическая программа для USB 108C:0155. Только чтение данных, без изменения параметров велосипеда.

## Возможности
- USB-открытие, разрешения Android, interrupt IN/OUT, handshake.
- Автоматические 21 тест: 7 CID (20, 22, 39, 3A, 5D, 5E, 5F) × 3 варианта Seq.
- UDS TesterPresent (3E 00), чтение DID (22 02 20), дополнительные DID по желанию.
- Ручная проверка CID, вариантов Seq и DID.
- Полный USB HEX, классификация ответов и экспорт JSON.
- Остановка, настройка времени ожидания, русский интерфейс.

## Как получить APK
GitHub → Actions → Bosch BES2 Android APK → успешный запуск → Artifacts → Bosch-USB-Lab-3-debug-APK. В архиве находится app-debug.apk.

Альтернатива: Android Studio, JDK 17, SDK 35. Команда Gradle 8.10.2: `gradle testDebugUnitTest assembleDebug`.

## Порядок проверки
1. Подключите Intuvia к Android-планшету через USB OTG.
2. Нажмите «Найти и подключить», подтвердите USB-разрешение.
3. Запустите «Проверить USB handshake»: ожидаемый ответ 00 01 02.
4. Запустите «АВТО · проверить все 21 комбинацию».
5. Сохраните JSON и проверьте его перед отправкой: в сырых данных могут быть идентификаторы устройства.

## Ограничения
Подтверждены USB VID:PID и handshake. Полный формат Bosch transport wrapper, состояние Seq, initial empty и чтение DID на данном велосипеде пока не подтверждены. Статусы UDS_POSITIVE_CANDIDATE / UDS_NEGATIVE_CANDIDATE означают совпадение структуры байтов, а не гарантированно декодированный ответ ECU. 00 FF не является стандартным UDS NRC. Многофреймовые ответы логируются без неподтверждённого flow-control.

Приложение не содержит команд записи, сброса, обновления прошивки или security access.
