# Bosch BES2 Windows: чтение Intuvia через USB

Программа читает Intuvia BUI255 через штатный HID `108C:0155` без замены драйвера. Реальные ответы подтвердили версии ПО и оборудования, пробег и RAW нескольких других DID. Формат языка дополнительно установлен по оригинальному коду публичной прошивки. Доступ к диагностике двигателя и аккумулятора пока не подтверждён.

[Исправление первого USB-чтения](BES2-TRANSPORT-FINDINGS.md) · [Кодировки BUI и границы исследования](BES2-BUI-ENCODINGS.md).

## Запуск

Запустите **BoschBES2Auto.exe**, выберите DID на вкладке **«Параметры BUI»** и нажмите **«ПРОЧИТАТЬ ВЫБРАННЫЙ ПАРАМЕТР»**. Один запуск выполняет новый handshake и не более одного запроса ReadDataByIdentifier `22`, затем закрывает поток. Автоматического сканирования нет. Самостоятельный EXE не требует отдельно установленного .NET или Python.

В таблице отдельно показаны статус расшифровки, наличие физического ответа в истории исследования и результат чтения в этом окне. Исторические значения не подставляются как текущие. Расшифрованный результат вынесен из HEX-лога. Есть остановка, сравнение JSON и задержка после handshake 0–3000 мс.

| DID | Статус формата | Что установлено |
|---|---|---|
| 0220 | VERIFIED | Версия ПО, четыре десятичных компонента; на велосипеде 5.9.2.0 |
| 0221 | VERIFIED | Версия оборудования; на велосипеде 0.0.2.2 |
| 0222 | RAW_ONLY | День, месяц, код года; календарный отсчёт года неизвестен |
| 0230 | RAW_ONLY | Ответ получен; таблица аппаратных вариантов неизвестна |
| 0245 | RAW_ONLY | Максимум скорости поездки; масштаб счётчика неизвестен |
| 0249 | VERIFIED | uint32 BE в метрах → км; 2326.6 км сопоставлены с дисплеем владельцем |
| 024A | VERIFIED для известных кодов | 01=English; таблица из прошивки, код 07 остаётся RAW_ONLY |
| 024B | RAW_ONLY | Перекодировка enum известна; независимая таблица km/mi не установлена |
| 024C | NOT_TESTED | Нет физического чтения; в исследованном дампе заглушка NRC 11 |
| 0250 / 0251 | NOT_TESTED | Прежние NO_DEVICE не отправили запрос; в дампе заглушки NRC 11 |

Версия публичного дампа совпадает с прочитанной версией ПО; идентичность всего содержимого памяти физическому устройству не проверялась. Для даты `13 16` установлены день 2, месяц 6 и код года 22. Программа не превращает это в вымышленный 2019 год/неделю 22 или полный 2022 год.

Если HID не найден, приложение делает максимум три **пассивных перечисления** с паузой 150 мс. Это не три диагностических сеанса. Если интерфейс не появился, NO_DEVICE означает ноль USB-open, handshake и запросов: проверьте включение Intuvia и кабель. Отказы после открытия не запускают новые попытки.

## Отчёты и границы

JSON в `reports/` рядом с EXE сохраняет результат, выбранный DID, все 65-байтовые Windows / 64-байтовые Bosch сообщения, UTC и монотонные временные точки. RAW_ONLY сохраняет байты и объяснение без увеличения числа подтверждённых значений. `00 FF` остаётся отдельной транспортной ошибкой; корректный NRC отделяется от неизвестных кадров.

`InitialSwaTransport.cs` содержит проверенный **начальный** обмен SWA. Полное управление sequence/ACK/очередью, общий CAN router, многокадровый ISO-TP и DU/BMS не реализованы. Каждый ответ проверяется по поддерживаемому заголовку, CID, SID, DID и длине. Содержимое после CAN-записи не декодируется.

DID 0245 — рекорд поездки, а не найденный ограничитель педального ассиста. Изменение максимальной скорости помощи и произвольных переменных не подтверждено. Программа не отправляет запись параметров, SecurityAccess, сбросы, команды движения или прошивки. Подробные адреса функций, таблица языков и недостающие сведения DU/BMS приведены в [отчёте исследования](BES2-BUI-ENCODINGS.md).

Полные отчёты могут содержать идентификаторы и остаток буфера памяти; они остаются локальными. Публичные тестовые фикстуры используют синтетический хвост.

## Командная строка

```
BoschBES2Auto.exe --enumerate --report-dir C:\Reports
BoschBES2Auto.exe --probe --did 024A --delay-ms 0 --report-dir C:\Reports
```

`--enumerate` не открывает HID и ничего не отправляет. Коды выхода: 0 — выполненное перечисление/подтверждённое чтение; 2 — неверные аргументы; 3 — значение не подтверждено; 4 — ошибка сохранения; 130 — отмена. Это GUI EXE: в PowerShell для автоматизации используйте `Start-Process -WindowStyle Hidden -Wait -PassThru` с перенаправлением stdout/stderr. Отмена в интерфейсе доступна кнопкой СТОП.

## Сборка и проверки

```
dotnet run --project windows/BoschBES2.Tests -c Release
dotnet run --project windows/BoschDiagnostic.Tests -c Release
dotnet run --project windows/BoschSniffer.Tests -c Release
dotnet publish windows/BoschBES2Auto -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:PublishTrimmed=false -o windows-dist
```

Локально прошли **145 protocol assertions, 64 offline session checks и 20 PCAP checks**. Они используют fake HID и не доказывают физическую работу новой сборки. Рабочие аппаратные чтения хранятся отдельно. Дополнительно проверены создание GUI, отдельное отображение результата и компоновка 900×650 / 1200×800 без HID.

Workflow **Bosch BES2 Windows EXE** запускает три набора тестов и публикует оба самостоятельных EXE. Артефакт **Bosch-BES2-Windows-USBPcap-Sniffer**. Сниффер требует установленного USBPcap; физический захват в этом исследовании не проверен, драйвер не устанавливался.
